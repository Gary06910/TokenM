# Token M 微信小程序

这是可导入微信开发者工具的原生小程序目录，入口为 `wechat-miniapp/`：

- `miniprogram/`：WXML/WXSS/JavaScript 页面与组件
- `cloudfunctions/tokenm-api/`：CloudBase 云函数及生产/测试分层
- `config/`：项目、数据库规则、索引、环境和模板配置示例
- `project.config.json`：公共 DevTools 配置；真实 AppID 放在被忽略的 `project.private.config.json`

先阅读 [部署说明](../docs/wechat-miniapp/DEPLOYMENT.md) 和 [提交清单](../docs/wechat-miniapp/SUBMISSION_CHECKLIST.md)。仓库不包含真实 AppID、EnvID、Template ID、AppSecret 或 Desktop credential。
